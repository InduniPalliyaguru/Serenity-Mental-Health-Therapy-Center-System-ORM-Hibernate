### 🚀 Key Architecture & Advanced Features

* **⚡ Hibernate 2nd-Level Caching:** Integrated advanced second-level caching mechanisms to optimize heavy data retrieval performance, minimizing relational database overhead and latency.
* **🔒 Account Lockout Security:** Engineered a robust login gate featuring a 3-attempts failure threshold counter that dynamically locks entry upon consecutive unauthorized access failures.
* **📈 Dynamic Analytics Dashboard:** Built interactive bar charts and pie charts that extract real-time database query statistics to visually monitor therapist performance indexes and program enrollments.
* **🛡️ Role-Based Access Control (RBAC):** Structured distinct graphical views and operational access boundaries separating the **Admin role** (clinical staff/program setup) and the **Receptionist role** (patient schedules/payments).

---

### 📂 Core Functionalities Implemented

* **💻 Clinical Management:** Comprehensive digital tracking modules for Therapist onboarding, Patient profiling, and secure Medical History logging.
* **📅 Smart Appointment Scheduling:** A synchronized booking module mapped directly to real-time therapist availability grids to prevent booking conflicts.
* **💰 Finance & Auditing:** Seamless tracking for multi-program enrollment fees, advance/pending balance processes, along with date-filtered transaction metrics for easy business auditing.

---

### 🛠️ Tech Stack & Implementation

* **Frontend UI:** JavaFX (Structured on top of a Clean Layered Architecture)
* **ORM Framework:** Hibernate ORM (Mapping business entities smoothly into database collections)
* **Database Engine:** MySQL
* **Cryptography:** BCrypt (For industry-standard, secure password hashing and encryption)
* **Development Environment:** IntelliJ IDEA
